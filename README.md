# 📊 Análisis Comparativo de Tiendas - Proyecto en Google Colab

Este proyecto realiza un análisis completo de datos de cuatro tiendas diferentes con el fin de determinar cuál de ellas es la mejor opción para comercializar productos, basándose en métricas como ingresos, calificaciones, envíos y comportamiento de ventas.

## 🧰 Requisitos

Para ejecutar este proyecto necesitas tener acceso a [Google Colab](https://colab.research.google.com) y una cuenta de Google.

### Dependencias
Este proyecto utiliza las siguientes bibliotecas de Python:

- `pandas`
- `matplotlib`
- `numpy`

Estas vienen preinstaladas en Google Colab, por lo tanto, no necesitas instalar nada adicional.

## 🚀 ¿Cómo ejecutar este proyecto?

1. Abre el archivo `.ipynb` del proyecto en Google Colab.
2. Ejecuta las celdas en orden para:
   - Cargar los datos.
   - Realizar análisis estadístico.
   - Visualizar los datos mediante gráficas.
   - Generar una recomendación final con justificación.

## 📂 Estructura del Proyecto

- **Carga de datos**: Se importan los datasets de cada tienda.
- **Análisis estadístico**:
  - Ingresos totales.
  - Ventas por categoría.
  - Promedios de calificación.
  - Productos más y menos vendidos.
  - Costo de envío promedio.
- **Visualizaciones**:
  - Gráficos de barras, líneas y dispersión para cada análisis.
- **Informe final**:
  - Redactado en formato Markdown dentro del Colab.
  - Incluye tabla comparativa y recomendación basada en métricas.



## ⚠️ Posibles Problemas

- **Error de carga de datos**: Verifica que los DataFrames `tienda`, `tienda2`, `tienda3`, y `tienda4` estén correctamente definidos o cargados.
- **Visualizaciones vacías**: Asegúrate de ejecutar las celdas de análisis antes de generar gráficos.
